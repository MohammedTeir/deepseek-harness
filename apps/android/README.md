# DeepSeek Harness Android prototype

English | [中文](README.zh.md)

Kotlin/WebView carrier for the original Harness frontend and a native-only approved pwd diagnostic. The embedded Harness runtime is unavailable: this is not a complete standalone Android agent. Chat, sessions, terminal, plugins and model calls are not enabled by the carrier.

Start with [build instructions](../../ANDROID_BUILD_GUIDE.md), [audit](../../ANDROID_PORT_AUDIT.md), [compatibility](../../ANDROID_COMPATIBILITY_MATRIX.md) and [current evidence](../../ANDROID_PORT_STATUS.md). No original UI or agent source is replaced. The runtime probe is diagnostics only.
