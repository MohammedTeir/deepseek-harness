# DeepSeek Harness Android 原型

[English](README.md) | 中文

此 Kotlin/WebView 容器使用原始 Harness 前端，并提供仅限原生界面批准的 pwd 诊断。嵌入式 Harness 运行时尚不可用：这不是完整的独立 Android 智能体。容器尚未启用聊天、会话、终端、插件和模型调用。

请先阅读[构建说明](../../ANDROID_BUILD_GUIDE.md)、[审计](../../ANDROID_PORT_AUDIT.md)、[兼容性](../../ANDROID_COMPATIBILITY_MATRIX.md)和[当前证据](../../ANDROID_PORT_STATUS.md)。原始界面和智能体源码均未被替换。运行时探测程序仅用于诊断。
